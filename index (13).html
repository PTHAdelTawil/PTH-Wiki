Fast fertig — Zugangscode einrichten

Statt Discord-Login gibt's jetzt einen gemeinsamen Zugangscode fürs Team. Es werden dabei keine persönlichen Daten (kein Name, keine E-Mail, keine Discord-ID) gespeichert — nur eine anonyme Sitzung.

  1. Kostenlosen Account auf supabase.com erstellen, neues Projekt anlegen
  2. Im SQL Editor ausführen: 
    create table docs (
  id uuid primary key default gen_random_uuid(),
  parent_id uuid references docs(id) on delete cascade,
  title text default '',
  body text default '',
  position int default 0,
  updated_at timestamptz default now()
);

alter table docs enable row level security;

-- jeder mit gültiger (auch anonymer) Sitzung darf lesen/schreiben
create policy "authenticated read" on docs for select using (auth.role() = 'authenticated');
create policy "authenticated insert" on docs for insert with check (auth.role() = 'authenticated');
create policy "authenticated update" on docs for update using (auth.role() = 'authenticated');
create policy "authenticated delete" on docs for delete using (auth.role() = 'authenticated');
  3. Unter Authentication → Sign In / Providers die Option "Allow anonymous sign-ins" aktivieren
  4. Unter Project Settings → API die Project URL und den anon public key kopieren, unten in index.html bei SUPABASE_URL / SUPABASE_ANON_KEY eintragen
  5. Einen eigenen Zugangscode ausdenken (z. B. pth-modding-2026) und dessen Hash erzeugen: Browser-Konsole (F12) öffnen und einfügen: 
    crypto.subtle.digest('SHA-256', new TextEncoder().encode('DEIN-CODE'))
  .then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
    Den ausgegebenen Hash unten bei ACCESS_CODE_HASH eintragen (nicht den Klartext-Code!)
  6. Datei speichern, neu hochladen, Zugangscode ans Team weitergeben (z. B. im Discord-Server) — fertig

Ehrlich gesagt: Ein gemeinsamer Code ist einfacher als Discord-Login, aber weniger streng — jeder mit dem Code kommt rein, unabhängig davon wer er ist. Für ein Team, das sich vertraut und den Code nicht weiterverbreitet, reicht das meistens locker.
